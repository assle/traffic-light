## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues for `assle/traffic-light`. See `docs/agents/issue-tracker.md`.

### Triage labels

The repo uses the five default triage label roles. See `docs/agents/triage-labels.md`.

### Domain docs

Domain documentation uses the single-context layout. See `docs/agents/domain.md`.

### Plans and documents

Treat the current workspace code as the source of truth. When updating an existing plan or document, rewrite the affected sections to describe the complete current state; do not append patch-style or delta descriptions such as “add,” “change,” or “supplement.” Change history belongs in Git history.
