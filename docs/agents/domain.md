# Domain Docs

This repo uses a single domain context.

## Before exploring

Read:

- `CONTEXT.md` at the repository root.
- Relevant ADRs under `docs/adr/`, if that directory exists.

Proceed silently when an optional document is absent.

## Vocabulary

Use the canonical terms defined in `CONTEXT.md` in issues, specifications, test names, reports, and implementation discussions.

Do not replace a canonical term with a synonym listed under `_Avoid_`.

When required terminology is missing or conflicts with the code, use the `domain-modeling` skill to resolve it before extending the glossary.

## Decisions

Record an ADR only when a decision is difficult to reverse, surprising without context, and resolves a real trade-off.
